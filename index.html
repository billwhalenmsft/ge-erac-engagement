Known limitations and exclusions

  • Normal updates can retain legacy managed components already installed in a target, even when the updated app no longer selects them.
  • No demo-data archive is approved; external-use provenance remains withheld.
  • No security roles, flows, connections, plug-ins, connectors, or production integration package is included.
  • Actuarial, legal, routing, migration, Copilot, and production Power BI depth remain Phase 2 work.
