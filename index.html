Guided install

Install the managed solution

These steps are for a Power Platform administrator. Start in a non-production environment. The package has zero declared missing dependencies, but a clean-first-install test is not claimed.

  1. Choose and protect the target

    Select a sandbox or developer environment. Confirm the change window, backup posture, capacity, licensing, and administrator access before importing.

  2. Download and verify the managed ZIP

    Download ERACLiteCRM_managed.zip. Confirm it is 141,342 bytes and its SHA-256 ends in ...794cb2afc; the full value is in the integrity section.

  3. Open Solutions in the target environment

    In the Power Apps maker portal, select the target environment, open Solutions, and choose Import solution.

  4. Upload and review

    Browse to the managed ZIP, continue through the import review, and confirm the solution name GEERACLiteCRM and version 1.0.0.1.

  5. Import without bypasses

    Start the normal import and wait for a successful result. Do not use force-overwrite, stage-and-upgrade, uninstall, or dependency bypass as a shortcut.

  6. Open and validate the app

    Open ERAC Lite CRM, confirm navigation and forms load, and complete the verification checklist below before assigning access.

  7. Apply customer-owned controls

    Assign approved security roles and ownership, then plan data migration, integrations, ALM, monitoring, and support separately. None of those are installed by this package.

Before you import

  • +Non-production target selected
  • +System Administrator or equivalent import access
  • +Backup or target baseline captured
  • +Package hash verified
  • +Security, ownership, and data plan identified
  • +Customer or partner owner available for validation
No sample data is installed. The app will open without customer records until your approved data load or integration is completed.
Administrator option: PAC CLI import

Use this only if your administrator already follows a governed PAC CLI deployment process.

pac solution import --environment https://TARGET.crm.dynamics.com `
  --path .\ERACLiteCRM_managed.zip `
  --async true `
  --max-async-wait-time 60

Replace TARGET with the approved environment URL. Never place credentials in a script or package.

After import

Verify before handoff

A successful import is the start of validation, not the end. Record the result and keep the package hash with the change record.

Solution and app checks

  • Solution GEERACLiteCRM shows version 1.0.0.1 and managed state.
  • The ERAC Lite CRM model-driven app appears and opens without an app validation error.
  • Navigation contains the intended ERAC areas and the portable Account form loads.
  • The selected views and web resources render without source-environment URLs.

Data and operational checks

  • No demo or customer records were created by the solution import.
  • If this was an update, compare pre/post record IDs and counts before sign-off.
  • Assign customer-approved security roles; the package does not include them.
  • Document target owner, import result, package hash, and next implementation actions.
If the import fails: stop and capture the import error, target environment, solution version, and exact package hash. Do not uninstall existing components or bypass dependencies. Share the evidence with the Microsoft and implementation-partner team for a reviewed recovery plan.
